## 运行时报错修复（用户用开发者工具运行后反馈）

修复 4 类控制台报错：
1. **分享海报生成失败 (canvas width/height 0)**：重写 `components/share-poster/share-poster.js`，`wx.canvasToTempFilePath` 显式传入 `x/y/width/height/destWidth/destHeight`（缓冲尺寸 = 750*dpr × 1334*dpr）；`getDpr()` 改用 `wx.getWindowInfo`；canvas CSS 尺寸由 375×667 改为 300×533，WXSS 同步修正。
2. **`wx.getSystemInfoSync is deprecated`**：`app.js` 与 `custom-tab-bar/index.js` 迁移到 `wx.getWindowInfo`（+ getDeviceInfo/getAppBaseInfo，仅保留兜底）。`share-poster.js` 内的 getSystemInfoSync 兜底已彻底移除。
3. **`[渲染层错误] Expected updated data but get first rendering data`**：`components/empty-state/empty-state.js` 原在 `lifetimes.attached` 中 setData（display* 字段未进初始 data）。改为在 data 中声明 display* 默认值，并用 `observers` 在属性变化时同步——属于数据绑定机制，不再触发渲染层告警。
4. **`appLaunch with non-empty page stack`**：`pages/detail/detail.js` 在无 id 时用 `wx.redirectTo` 跳转 tabBar 页面（非法，应走 switchTab/reLaunch）。改为 `wx.reLaunch({ url: '/pages/index/index' })`。

验证：全部 .js 通过 `node --check`，全部 .json 合法。libVersion 3.17.0，appid 已配置。
注：`lazyCodeLoading: requiredComponents` 已开，custom-tab-bar 三页均通过 `getTabBar().setData({selected})` 正确高亮（index=0, rank=1, mine=2）。
